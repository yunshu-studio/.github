## 👋 关于云枢科技

湘潭云枢科技有限责任公司是一家关注**可信人工智能与垂直场景智能化**的技术企业。

我们从真实业务流程出发，将大模型能力、专业知识、软件工程和可信机制结合起来，构建能够进入高校、科研、企业及专业服务场景的智能系统。

> **模型能力 × 业务知识 × 工程系统 × 可信机制**  
> 不是让 AI 只会回答问题，而是让它能够可靠地完成工作。

## 🚀 代表工作

| 项目或方向 | 解决的问题 | 当前阶段 |
| --- | --- | --- |
| **AI 辅导员** | 面向高校学生服务和辅导员工作流，提供知识问答、事务提醒、信息收集、风险预警与通知触达能力 | 场景试点与持续迭代 |
| **CorrectKV** | 对结构化生成中的缓存复用结果进行字段级验证，并对不可靠部分执行局部重算 | 技术研究与工程验证 |
| **LegalGuard** | 面向法律大模型开展动态基准构建、可信评测、法源核验与安全护栏研究 | 研发验证 |
| **云枢标盾 BidGuard** | 对招标文件、投标材料和评标内容进行合规检查与风险识别 | 产品研发 |
| **垂直知识库平台** | 为高校、科研院所和企业提供知识增强、权限隔离、多租户及私有化部署能力 | 工程交付 |

> 部分项目仍处于研发、试点或知识产权保护阶段，因此暂未公开完整源代码。  
> 我们将逐步开放适合公开的工具、技术文档、评测基准和工程组件。

## ⚙️ 工程原则

<table>
  <tr>
    <td align="center"><strong>场景先于模型</strong></td>
    <td align="center"><strong>证据先于答案</strong></td>
    <td align="center"><strong>边界先于能力</strong></td>
    <td align="center"><strong>交付先于炫技</strong></td>
  </tr>
  <tr>
    <td valign="top">先理解真实业务，再选择技术路线。</td>
    <td valign="top">无法追溯来源的结论，不应被当作可靠结果。</td>
    <td valign="top">权限、数据隔离和安全策略必须提前设计。</td>
    <td valign="top">Demo 可以惊艳，生产系统必须稳定。</td>
  </tr>
</table>

<p align="center">
  <strong>当系统无法确认结果时，应当安全回退，而不是假装正确。</strong>
</p>
